# 中文简历排版规范 × Playwright PDF 中文字体嵌入调研报告

> A 部分为排版规范（来源：clreq、知乎、高校就业网、日式履历书、中文文案排版指北等）；B 部分为技术方案（Playwright 官方文档 + 本机 Chromium 151 实证测试）。

## A. 中文简历排版规范

### A1 核心参数表

| 项目 | 推荐值 | 备注 |
|---|---|---|
| 页面 | A4 210×297mm 单栏纵向 | 国内标准 |
| 页边距 | 上下 2.0–2.5cm，左右 2.0–2.5cm | 紧凑档 1.5cm；日式履历书四边 20–25mm |
| 姓名 | 16–20pt 加粗 | 全文最大字号，置顶 |
| 模块标题 | 12–14pt 加粗 | 比正文大 1–2 级 |
| 条目标题（职位/学校） | 11–12pt 加粗 | 与正文同级或大 1 级 |
| 正文 | 10.5pt（五号） | 区间 10–11pt，打印下限 9pt |
| 行距 | 1.15–1.5，舒适区 1.3–1.5 | 10.5pt×1.5≈15.75pt |
| 模块间距 | 8–12pt；模块内条目间 4–6pt | — |
| 每行字数 | 35–45 字（约 40 字） | 日式"一行 40 字"惯例 |
| 字体数量 | 全文 1–2 种 | 超过即显杂乱 |
| 页数 | 应届生 1 页；5–10 年经验 1–2 页 | 国内硬惯例 |

### A2 混排、标点与字体层级

- **中西文混排（盘古之白）**：中西文之间、中文与阿拉伯数字之间加一个空格；数字与单位之间加空格（10 Gbps）；例外：度数/百分比不加空格（90°、15%），全角标点两侧不加。
- **clreq 量化标准**：汉字与西文/数字间字距 ≤1/4 汉字宽；行末标点挤压为 1/2 汉字宽；中西间距上限约 1/3 汉字宽。
- **避头尾**：点号（，。、；：？！）、后引号/括号/书名号、连接号、间隔号不得居行首；前引号/括号/书名号不得居行尾；GB 级追加"分隔号不得行尾"。处理原则"先挤进，后推出"。
- **标点悬挂**：中文出版物一般不悬挂；clreq 注明行尾点号悬挂做法源自日文排版。
- **字体层级**：Windows 现实档——正文微软雅黑（互联网岗）或宋体（正式岗），标题黑体/雅黑 Bold，英文配 Calibri/Times New Roman；高端档——思源黑体 Regular 正文 + Bold 标题，思源宋体用于文学性文本。日式同源惯例："明朝体正文 + 哥シック体标题"，全文黑色、左对齐、不用斜体下划线。
- **日期与分隔符**：日期统一 `YYYY-MM`（2023-09 至 2023-12 / 至今），禁用中文日期与格式混用；信息栏分隔用" · "或" | "，全篇统一；"——"仅作文内解释。
- **区块顺序**：应届生 = 个人信息 → 教育背景（置顶）→ 实习/项目（逆序）→ 技能 → 荣誉；有经验者 = 个人信息 → 工作经历（置顶，逆序）→ 教育背景 → 技能。原则：最强内容放最前（HR 初筛仅 6–10 秒）。

## B. Playwright PDF 中文字体嵌入技术方案

### B1 本机实证结论（Chromium 151 + Playwright Python）

1. **file:// 下 @font-face 完全可用**：相对路径（`./fonts/x.otf`）与绝对路径（`file:///C:/...`）均加载成功（`document.fonts` status=loaded），无 CORS 阻断。
2. **静态字体正确嵌入**：TTF/TTC（思源黑体、SimSun、SimHei、msyh）均嵌入为 Type0/CID 字体，basefont 带子集前缀（如 `AAAAAA+SourceHanSansSC-Medium`），文本可搜索、可复制。
3. **可变字体必须禁用**：NotoSansSC-VF 无论写 `font-weight: 100 900`、单字重还是 `font-variation-settings`，一律降级为 **Type3 字体**（basefont 为空、逐字符拆分，实测 26 个 Type3）。视觉正常但 PDF 无真实字体名。**必须使用静态字体文件**。
4. **子集化确认**：17MB 的字体文件嵌入 PDF 后每个子集约 0.6MB，整份测试 PDF 仅 120KB——Chromium 打印自动子集化，无需手动裁剪。
5. **page.pdf 默认值是坑**：`format` 默认 Letter、`printBackground` 默认 false、按 print 媒体渲染；颜色需 CSS `-webkit-print-color-adjust: exact` 才精确。

### B2 落地代码

CSS（模板内）：

```css
@font-face {
  font-family: 'SourceHanSansSC';
  src: url('./fonts/SourceHanSansSC-Regular.otf') format('opentype');
  font-weight: 400;
}
@font-face { /* Bold 同理，换文件与 weight */ }
:root { -webkit-print-color-adjust: exact; print-color-adjust: exact; }
@page { size: A4; margin: 2cm; }
body {
  font-family: 'SourceHanSansSC', 'Microsoft YaHei', 'SimSun', sans-serif;
  font-size: 10.5pt; line-height: 1.5;
}
```

Python：

```python
from pathlib import Path
from playwright.sync_api import sync_playwright

html = Path("resume.html").absolute()
with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    page.goto(html.as_uri())                 # file:///E:/.../resume.html
    page.wait_for_load_state("networkidle")  # 务必等字体加载完
    page.pdf(
        path="resume.pdf",
        format="A4",
        print_background=True,
        prefer_css_page_size=True,           # 采用 CSS @page 尺寸
        margin={"top": "2cm", "bottom": "2cm", "left": "2cm", "right": "2cm"},
    )
    browser.close()
```

**最稳妥写法**：静态字体文件置于项目 `fonts/` 目录 → HTML 用相对路径 `@font-face` → `as_uri()` 以 file:// 打开 → 显式 `format="A4"` + `print_background=True` → 生成后用 pymupdf 校验字体为 Type0 子集（非 Type3）。

### B3 字体文件推荐清单

| 字体 | 下载源 | 许可证 |
|---|---|---|
| 思源黑体 Source Han Sans SC（Regular/Medium/Bold 静态 OTF，勿用 Variable） | https://github.com/adobe-fonts/source-han-sans/releases | SIL OFL 1.1 |
| Noto Sans SC / Noto Serif SC（静态版） | https://github.com/notofonts/noto-cjk | SIL OFL 1.1 |
| Noto Sans SC（Google Fonts 页，注意默认下发可变字体） | https://fonts.google.com/noto/specimen/Noto+Sans+SC | SIL OFL 1.1 |
| 系统字体 SimSun / SimHei / Microsoft YaHei / DengXian / FangSong / KaiTi | C:\Windows\Fonts | Microsoft 专有（限 Windows 环境使用） |

许可证确认：思源黑体与 Noto CJK 均为 SIL Open Font License 1.1（https://openfontlicense.org/ ），允许自由使用、嵌入、再分发（不可单独售卖字体本身）。

**宋体 vs 黑体 PDF 渲染差异**（本机截图实证）：宋体为衬线、横细竖粗、笔画对比强，适合正式/传统岗位；黑体（SimHei）/微软雅黑/思源黑体为无衬线、笔画均匀，适合互联网/现代风格；两者均正常子集嵌入，文本层完好。
